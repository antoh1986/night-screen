# Экран: температура, яркость и контраст

GUI с ползунками и полями ввода для цветовой температуры (1000–10000 K),
яркости (10–100 %), контраста (30–150 %) и центра контраста (0–100 %).
Меняется гамма-таблица видеокарты,
подсветка монитора не трогается, поэтому ШИМ на низкой яркости не появляется.

- Запуск: `./run.sh` или ярлык «Экран: температура и яркость» на рабочем столе.
- Нужен Python 3 с tkinter и библиотеки libX11/libXrandr (есть в Mint по умолчанию).
  `xsct` не обязателен: он нужен только чтобы при запуске узнать текущие значения,
  если экран изменили не из этого окна.
- Ползунок: мышь, колесо, стрелки (шаг), PageUp/PageDown (×10).
- Поле ввода: число и Enter; значение за пределами зажимается в диапазон.
- Пресеты (День/Вечер/Ночь/Глубокая ночь) меняют только температуру и яркость.
  «Сбросить всё» внизу возвращает всё: 6500 K, 100 %, контраст 100 %, центр 50 %.
  У контраста и центра есть свои кнопки «Сбросить».
- Контраст — наклон вокруг центра. Выше 100 %: тона темнее центра темнеют, светлее —
  светлеют (крайние обрезаются). Ниже 100 %: всё стягивается к центру.
- Центр контраста задаёт, какие тона при контрасте выше 100 % светлеют, а какие
  темнеют. Вправо — светлеет больше, влево — темнеет больше (как цвет дорожки).
  Чтобы тусклые рамки становились ярче, а не исчезали, — ≈ 80–90 %.
  100 — простое усиление (чёрный остаётся), 0 — всё темнеет (белый остаётся).
  Внутри значение инвертируется: уровень серого, который контраст не трогает,
  = 100 % − значение ползунка.
- Порядок: сначала контраст, потом яркость и температура. Поэтому яркостью можно
  притушить даже очень контрастную картинку.
- Настройки остаются после закрытия окна. Последние значения лежат в
  `~/.config/night-screen/state.json`; если экран при запуске отличается от них
  (после перезагрузки, после `xsct`), окно показывает реальное состояние.
- Файлы: `night_screen.py` — окно, `gamma.py` — запись гамма-таблицы через XRandR
  (при контрасте 100 % совпадает с `xsct` до единицы).
- Пределы и пресеты — в начале `night_screen.py`.
- Вернуть экран как был: «Сбросить всё» или `xsct 6500 1`.
