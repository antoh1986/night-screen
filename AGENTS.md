# AGENTS.md

Небольшое десктоп-приложение для Linux (X11): окно с ползунками, которое
меняет температуру, яркость и контраст картинки на экране. Подробности и
управление — в [README.md](README.md).

## Суть

Меняется только гамма-таблица видеокарты (XRandR), подсветка монитора не
трогается. Поэтому ночью можно сделать экран темнее и теплее без ШИМ-мерцания,
которое появляется на дешёвых мониторах при низкой аппаратной яркости.

Порядок обработки: контраст (наклон вокруг «центра») → яркость → температура.
Яркостью всегда можно притушить даже очень контрастную картинку.

## Файлы

- `night_screen.py` — окно на tkinter, ползунки, пресеты, сохранение состояния
  в `~/.config/night-screen/state.json`.
- `gamma.py` — расчёт таблицы и запись через ctypes (libX11 + libXrandr). Формулы
  температуры и яркости повторяют `xsct`; при контрасте 100 % результат совпадает.
- `tray.py` — значок в трее (XApp.StatusIcon, GTK): левая кнопка — показать окно,
  правая — меню с пресетами. Отдельный процесс на `/usr/bin/python3` (там есть `gi`,
  у conda нет); его запускает само окно и сам он ничего не считает.
- `ipc.py` — абстрактный unix-сокет: один экземпляр окна, и по нему же трей и
  повторный запуск шлют команды `show`, `preset N`, `quit`.
- `run.sh` — запуск; ярлык на рабочем столе указывает на него. Автозапуск —
  `~/.config/autostart/night-screen.desktop` с `run.sh --tray` (окно скрыто).
- `night-screen.desktop.example` — шаблон автозапуска, `docs/` — скриншоты для README,
  `LICENSE` — MIT.

## Важно помнить

- Ползунок «Центр контраста» (0–150) инвертирован: в gamma уходит `100 − значение`
  (функция `pivot_level`). Правее 100 уровень отрицательный — чёрное поднимается.
- Крестик окна прячет его в трей, только если процесс трея жив (`_tray_alive`);
  иначе приложение закрывается. Выход при живом трее — пункт «Выход».
- Значок называется `org.x.StatusIcon.<prgname>`: в `tray.py` задан `night-screen`,
  иначе имя берётся от файла (`tray_py`) и конфликтует с чужим `tray.py`.
- Окно не должно блокироваться: запись таблицы занимает ~2 мс и делается
  прямо в главном потоке.
- Кнопка «Сбросить всё» возвращает всё к нейтральному виду; у каждого ползунка
  своя «Сбросить» (только это значение). Стандартные пресеты меняют только
  температуру и яркость; через «Сохранить» в пресет пишутся все четыре значения
  (`~/.config/night-screen/presets.json`).
